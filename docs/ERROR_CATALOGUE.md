## 1. Purpose and rules

1. Every failure that the Creator can see maps to exactly one `EM-` code. The Local Service maps internal exceptions to a code in the `http` module (ARCHITECTURE.md §4); the Editor never invents copy.
2. **Stack traces, exception class names, file paths of the installation, SQL text and provider payloads never appear in the UI.** They go to `logs/service.log` and the Diagnostics bundle only (`scr.diagnostics`). The UI shows the code (small, grey, copyable) so support can find the log line.
3. A code has one severity. If the same underlying cause can be a warning in one place and a blocker in another, two codes exist.
4. Copy is stored under i18n keys `err.<code>.title`, `err.<code>.body`, `err.<code>.action` (several actions joined with " · "; generated into `apps/ui/src/i18n/*.json` by `apps/ui/scripts/sync-error-copy.mjs`) (ACCESSIBILITY_AND_I18N.md). English is shown in the MVP UI (ADR-012); the Indonesian variant is used for Indonesian chat replies and for the later Indonesian UI.
5. The recovery action is a real button or link, not advice. If no action is possible, the only button is "OK" / "Oke" and the body says what will happen next.
6. Codes marked **reserved** below were already cited by other documents before this catalogue existed; their meaning is fixed by those documents.

## 3. Severity scale

| Severity | Meaning | UI treatment |
|---|---|---|
| info | Expected condition the Creator should know about; nothing failed | toast (auto-dismiss 6 s) or inline note; no sound |
| warn | Something degraded or was changed automatically; the task continues | toast with action (stays until dismissed) or inline banner |
| error | The task failed; the app is fine; the Creator can retry or change something | inline error card or modal with recovery button; code visible |
| fatal | Expertmotion cannot continue the session safely | full-screen dialog; offers Diagnostics and Restart; project checkpoint saved first when possible |
| deprecated | Code number retired or an alias another document used before this catalogue existed; never shown | the Local Service maps it to the canonical code named in the row |

## 4. Style guide for error copy

| Rule | Do | Do not |
|---|---|---|
| Lead with what happened, then what to do, in one or two sentences | "This file type is not supported. Convert it to MP4, MOV, WebM or MKV and import again." | "Error: unsupported container (probe failed)." |
| Plain words a beginner knows | "memory", "disk space", "internet", "key" | "heap", "OOM", "ENOSPC", "401", "token", "Remotion", "Chrome", "FFmpeg", "SQLite" |
| Name the thing by its UI label and element | "in Output Settings", "in File ▸ Project Settings" | "in the right panel" |
| The recovery action is the button label and a verb | "Try again", "Choose another model", "Free disk space", "Open Model Manager" | "OK" on an actionable error |
| Never blame the Creator | "The key was not accepted by OpenRouter." | "You entered an invalid key." |
| No exclamation marks, no humour, no jargon in Indonesian either | "Ruang disk hampir habis." | "Waduh! Disk penuh!" |
| Indonesian uses the friendly register ("kamu", GLOSSARY.md "Words to avoid"); the formal "Anda" is kept only in licence copy (EM-5xxx, shown on `scr.license`); same length and same action as the English | "Coba lagi"; "Periksa koneksi internet kamu" | "Coba lagi ya"; "Periksa koneksi internet Anda" (outside EM-5xxx) |
| Numbers carry units and are rounded | "Needs 2.4 GB free, 1.1 GB available." | "Needs 2483 MB." |
| Never promise what the app cannot verify | "The video is identical; only render speed changes." | "This will make rendering faster." |
| Codes are shown once, small, as `EM-3102`, copyable; never in the sentence | — | "Error EM-3102 occurred." |
| Placeholders always get a value; when the UI does not know one (QA 2026-10-25) the renderer (`formatErrorMessage`, `apps/ui/src/i18n/index.ts`) uses a generic noun for `{provider}` "the AI provider" / "penyedia AI", `{model}`, `{tool}`, `{agent}`, `{connection}`, `{preset}`, `{profile}`, `{scope}` (keys `ui.err.fallback.*`, quotes around them dropped), leaves out a sentence whose other values are unknown, and uses "this item" / "item ini" if nothing would remain | "Expertmotion could not reach the AI provider."; EM-1002 without sizes: "Trim or compress it, then import again." | "Expertmotion could not reach …." |

## 5. Log fields

Every error log line (JSON, `logs/service.log` or `logs/shell.log`) carries the common fields `ts`, `level`, `code`, `subsystem`, `projectId?`, `sessionId`, `component`, `message` (internal, English), `cause` (sanitised exception message), `stack` (service log only, never in UI), plus the code-specific fields listed in column "Log fields". Secrets are redacted by pattern before writing (ARCHITECTURE.md §9). Logs rotate after 7 days (NFR-111).

## 8. Placeholder vocabulary

Placeholders in curly braces are filled by the Local Service before the string reaches the Editor: `{name}` asset/project/clip label, `{size}`/`{limit}`/`{need}`/`{have}` human sizes with unit, `{duration}` as `m:ss`, `{percent}` integer, `{model}`/`{provider}`/`{agent}`/`{tool}` labels, `{preset}` Design Preset label in the current language, `{keys}` comma-separated Locked Keys in their UI labels (never raw `cut:3.transition`), `{date}` localised date, `{w}`/`{h}` integers, `{ctx}` tokens with thousands separator (EN `1,000`, ID `1.000`).

## 9. Change control

Adding a code: append to the right range, add FR/NFR links, add a TEST_PLAN case that triggers it, add both language strings. Removing a code: mark `deprecated` with the replacement; never reuse the number.
